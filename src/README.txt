KEY2 Remap 1.2（BlackBerry KEY2、Android 15と16、Magisk 31.1向け）

1. Magiskアプリからこのモジュールをインストールし、再起動します。
2. WebUI XでKEY2 Remapを開き、root権限とシェル権限を許可します。
3. 「キー」の画面では、修飾キーのタブとキーボード図でキーを選び、出力を選びます。
4. 「タッチ操作」の画面では、キーボードの表面をなぞる、払う、タップする操作に、キーやスクロールを割り当てます。
5. 保存して再起動すると反映されます。

LineageOS 22.2では、Androidの設定でBlackBerry用のキーボードレイアウトを選ぶと、このモジュールの割り当ての一部がそのレイアウトで上書きされることがあります。

【元に戻す】
Magiskでモジュールを無効化して再起動すると、導入前の状態に戻ります。
